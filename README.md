# Scoreboard Timer

A workout timer for iPhone, styled as a glowing LED scoreboard. No sound, so it never interrupts your music.

- **Intervals:** work and rest rounds, sets, rest between sets and a get-ready countdown
- **Count up** and **count down**
- **Rest:** one-tap presets for rest between strength sets

The background fills amber for work and cyan for rest, and the last three seconds flash. It keeps the screen awake while running and works in portrait and landscape.

## Install on iPhone

1. Open the GitHub Pages link in Safari.
2. Tap Share, then **Add to Home Screen**.
3. Open it from the home screen icon for a true full-screen view.

It's a single static page (`index.html`), with no build step.
